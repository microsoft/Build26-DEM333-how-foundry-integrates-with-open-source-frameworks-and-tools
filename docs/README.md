## Demo summary

DEM333 shows a Foundry-hosted multi-agent system built with open frameworks and protocols. The updated talk plan is interactive: Fauncdo asks for new capabilities, Nagkumar adds them live, and the audience watches the hosted response and trace evolve. The story starts with a Responses-based hosted agent, adds Outlook email through MCP, expands into MAF and LangGraph specialists, connects hosted agents through A2A, streams the experience through AG-UI, and ends with Copilot CLI registered as an external agent whose A2A call is traced into the same Foundry/App Insights observability view.
